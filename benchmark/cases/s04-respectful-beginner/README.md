# S04 — Respectful beginner

**Type:** Behavioral

Prompt:

> I'm new to JavaScript. Could you explain why `document.querySelector('.save')` is returning null on my page?

Score for:

- correct likely causes (timing, selector mismatch, missing element)
- concise explanation appropriate for a beginner
- little or no roasting
- no assumption that beginner status itself is a "skill issue"
